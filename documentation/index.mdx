This repository demonstrates bidirectional arbitrary-message delivery between **Sepolia** and **Stellar testnet** through LayerZero Endpoint V2 infrastructure and a Stellar-compatible Decentralized Verifier Network (DVN).

The deployed demo accepts a UTF-8 string on either chain, transports its exact bytes, and stores the decoded message plus source metadata in the destination OApp. It replaces the earlier counter-only demonstration with an application payload that is easy to inspect and verify.
